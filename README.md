# TrustVault

TrustVault is a secure document-sharing web application built with Django. It lets users share documents with specific people and control whether they can view, download, or edit them.

## Features

- User login and authentication
- Upload and manage documents
- Share documents with selected users
- Set view, download, and edit permissions
- Revoke document access
- Search documents
- Record actions and denied access attempts in an audit log
- Manage documents and view audit logs through Django Admin

## Technology Stack

- Python
- Django
- SQLite
- HTML and CSS

## Run Locally

1. Activate the project's virtual environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```
